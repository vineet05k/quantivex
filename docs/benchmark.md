Seeds 11, 22, 33, 44, 55 (each changes shot noise and Qiskit's layout search). Mean |error| ± standard error of the mean; paired difference = Qiskit - Quantivex (positive = Quantivex better). The paired p-value is an exact two-sided sign-flip permutation test over the 5 seed pairs (chosen after these seeds had already been run once, in response to the v1.2.0 audit; no other test was tried).
