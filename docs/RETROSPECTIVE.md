# Scientific scope - 1.3.0

The package contributes an inspectable integration and educational demonstrator.
UCCSD/VQE, calibration-aware mapping, readout rescaling, quantum blur and language-model
tool planning have prior art (see REFERENCES.md and the forensic audit). Substantial
scientific novelty or publication readiness has not been established.

The regenerated benchmark is a fixed-seed simulation of a historical calibration. It
reports random-only permutation statistics and descriptive selected-layout comparisons.
It does not establish superiority to Qiskit, hardware generalization, physical chemical
accuracy or quantum advantage. Since 1.2.0 the 95% radius uses empirical Bernstein where it is tighter; on the benchmark
this decides every best-chain result as OUTSIDE_TOLERANCE_95. Inconclusive results remain
possible and are an honest outcome, not an error to hide.

A research study would need a specified contribution, prospective devices/dates, repeated
independent seeds, suitable tuned baselines, model-mismatch analysis, and held-out agent
evaluations if the language interface is part of the claim. Those experiments have not
been created by the remediation work.
